# 01 全链路总览

本文描述整条管线的骨架和每个环节的设计决策。具体坑在各分篇。

## 0. 适用前提

- 目标：对一族**只差局部几何**的构型（典型：某个可动小部件的不同偏转角度）批量产出
  气动力/力矩数据表，供飞行动力学（6-DOF）或选型使用。
- 规模：单构型 10⁵~10⁶ 单元量级，单构型 ≤30 分钟，构型数 10~100。
- 手段约束：全自动无人值守（GUI 只在最后看结果），可断点续跑。

如果构型数 < 3 且几何一次成型，直接 GUI 操作更快，别上管线。

## 1. 管线五段

### ① 参数化几何（SpaceClaim/Discovery 脚本）
- 输入：一个包含"本体 + 可动件 + 外流场盒"的 STEP（mm）。
- 动作：按实测轴线旋转可动件到目标角度 → 布尔并集 → 导出 `.dsco`。
- 输出：每个构型一个 `.dsco`。
- 关键约束见 [02](02_spaceclaim_discovery.md)、[03](03_geometry_topology.md)。

### ② Watertight 网格（PyFluent, mode="meshing"）
- 固定配方：表面网格（曲率/邻近加密）→ Describe Geometry(fluid+solid) → Share Topology
  → 边界层棱柱 → poly-hexcore 体网格。
- 每一步的警告都要看：`stair-stepping`、`minimum orthogonal quality` 是后续发散的前期征兆。
- 关键约束见 [04](04_watertight_meshing.md)。

### ③ 求解（PyFluent, switch_to_solver）
- SST k-ω + coupled + 二阶；边界层构型用一阶格式起步 200 步再切二阶。
- 边界条件用 TUI + zone ID 设置，写完必须读回断言。
- 见 [05](05_solver_pitfalls.md)。

### ④ 力/力矩报告（两层）
- 原生报告定义（zone 级）：总力（N）+ 力矩（注意返回的是系数 Cm）。
- 逐面积分（field_data）：把某个面 zone 的每个面拿出来自己积分，用于"从一整张
  蒙皮里切出某个子部件的受力"。见 [06](06_field_data_postproc.md)。

### ⑤ 批量驱动（Python 子进程）
- 每个构型一个独立子进程（独立 Fluent 会话），崩溃不连坐；
- 以 summary 文件存在与否为断点标记，重跑自动跳过已完成构型；
- 每构型独立日志。

## 2. 贯穿全线的三个设计决策

**决策一：所有几何操作走 Discovery 脚本，不走 SolidWorks。**
SolidWorks 对穿插/零厚度接触的交互操作会拒绝（"厚度为 0 的实体"），而 Parasolid
内核的布尔可以吞掉大部分这类接触。Discovery 隐藏模式可以把内核能力脚本化。

**决策二：每个环节都有自校验。**
- 几何：布尔后实体数必须 == 预期；旋转前后体积不变（刚体）。
- 网格：负体积=0、阶梯化警告数、最小正交质量要进日志。
- 求解：入口速度写后读回；力爆炸早停（|F|>正常值 5 倍即杀）。
- 数据：驻点区压力必须为正、零偏转部件的力必须≈0、窗口面积必须等于该部件已知面积。

这套自校验在实战里抓出过：假收敛、力矩量纲错误、节点映射错位三个大坑，
每一个都不是靠眼睛看出来的。

**决策三：数据提取走 field_data 而不是 TUI。**
2025R2 砍掉了大片 TUI 表面工具菜单；而 field_data 接口稳定、可编程、能做任意
子区域积分。代价是必须自己处理节点映射和面积（见 06），已在模板里封装。

## 3. 目录与产物约定（推荐）

```
project/
├── runs/
│   ├── sweep/                 # 批量构型
│   │   ├── cfg_a.dsco         # 每构型一个 dsco
│   │   ├── cfg_a/             # 每构型一个运行目录
│   │   │   ├── cfg_a.cas.h5
│   │   │   ├── cfg_a.dat.h5
│   │   │   ├── cfg_a_summary.json
│   │   │   └── solve_cfg_a.log
│   │   └── driver.log         # 批量驱动日志
│   └── ...
└── results/
```

summary json 是断点续跑的标记：驱动看到它就跳过该构型。删掉某个构型的目录
即可强制重跑。
