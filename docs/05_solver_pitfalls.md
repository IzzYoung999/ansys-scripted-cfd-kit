# 05 求解侧常见陷阱

本文记录求解与报告环节的坑。每一条都真实在实际项目中出现过。

## 1. 气动力在 `-shadow` 面上（关键问题）

两 sided wall（一侧固体一侧流体）会生成**两个重叠的面 zone**：主面 +
`-shadow` 影子面，物理上是同一张皮。规则：

- **气动力（压力+剪切）长在流体侧那个 zone 上**，固体侧恒为 0。
- 哪个是"主面"哪个是"影子"**随网格翻转**：同一套管线，这次网格力在主面、
  下次可能在影子面。

**纪律**：报告定义的区域列表**永远把主面和影子面都放进去**（影子贡献恒 0，
无害），或者跑前用 `adj-zone-material` 自动探测哪边邻接空气。

## 2. 力矩报告的量纲陷阱

`solution.report_definitions.compute()` 返回值：

| 报告类型 | 返回 | 单位 |
|---|---|---|
| force | 原始力 | **N** |
| moment | **无量纲系数**（Cm = M/(q·A·L)） | 无量纲 |

证据：compute 输出表头印着 "Cm"；同一力矩自己逐面积分得 0.00226 N·m，
除以 q·A·L=0.1407 恰好等于报告值 0.0158。

**纪律**：任何"CFD 力矩和手算/文献对不上差几倍"的问题，第一反应查量纲：
用自己积分的 N·m 除以 q·A·L 再比，若对上了就是单位陷阱。力报告没这个问题。

## 3. 假收敛图谱

| 症状 | 真相 |
|---|---|
| 残差 1e-10，力全零 | 入口速度没写进去（TUI 缓存滞后，见 04 §7） |
| 残差 1e-6，力值可疑 | 报告区域不含 shadow 面（§1） |
| 每步 0.1 秒（正常要 1 秒+） | 流场没在动，网格规模对不上耗时 |

**每步耗时本身就是健全性指标**：记下正常构型的 s/iter，异常快 = 流动没发生。

## 4. 发散的识别与处置

识别（典型特征组合）：
- 力爆炸：0.3 N 量级 → 5 N，且侧力/滚转变号暴涨；
- transcript：`Reversed flow on XXXX faces (100.0% area) of pressure-outlet`、
  `turbulent viscosity limited ... in N cells`（N 接近总单元数）；
- 残差：连续性 1e7 量级。

处置序列（按成本排序）：
1. 查网格日志的 `stair-stepping`/`OQ`——棱柱退化是常见根因，回炉网格；
2. `expert.first_to_second_order_blending = 0` 一阶起步 200 步再切二阶；
3. 检查是否撞上退化拓扑（见 03 §2）——这种发散调任何求解参数都救不了。

`poor_mesh_robustness` 节点的子键是 `poor_mesh_numerics`/`poor_mesh_removal`
（没有 `enable` 键，直接设子键）。

## 5. 报告定义的区域参数

```python
rd.force["f_axial"] = {"force_vector": [0, 0, -1], "zones": [...]}   # ✓ zones
```

- 区域参数键是 **`zones`**；dict 里写 `locations` 会被静默丢弃。
- `compute(report_defs=[k])` 返回 `[{"cd": [值, ""]}]` 这类嵌套——解析写个
  容错的取值函数，别裸链。
- 力矩的 `mom_center`/`mom_axis` 是全局坐标——换参考点=纯数值平移，
  压心等不变量不受影响。

- [ ] 每步耗时在正常档位
