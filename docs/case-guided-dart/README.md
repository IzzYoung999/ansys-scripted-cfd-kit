# 案例：细长体 + 四尾舵的舵效测量（guided slender dart）

> 本目录是[工具箱](../../README.md)的**实战案例板块**：上述管线在"一根 255 mm
> 细长体、尾部四片可动舵"的构型上跑通并产出舵效数据表的完整记录。
> 方法细节都在工具箱正文，这里只讲项目侧的结论与数据。

## 1. 对象与目标

- 细长体弹身（轴对称，255 mm，参考面积 0.003118 m²），尾部 X 形布局：
  4 片固定翼 + 4 片嵌在翼面内侧的可动舵（舵翼共面，绕 45° 对角铰链线偏转）。
- 问题：单片舵偏 δ 度，全弹的滚转/侧力/俯仰响应是多少？
  （这是四舵混控表的一列，也是舵机选型与 6-DOF 控制的输入。）

## 2. 管线在此项目上的形态

| 环节 | 工具 | 产物 |
|---|---|---|
| 舵偏角参数化 | Discovery 脚本绕销孔铰链轴旋转 | 13 个构型 .dsco |
| 网格+求解 | PyFluent WT + SST k-ω（15 层棱柱 + 一阶起步） | 每构型 25 min |
| 分舵力 | 逐面积分（极坐标窗口） | 混控表 JSON |

## 3. 主要结果（V=17 m/s，单舵 ±15°）

| 量 | 值 | 设计含义 |
|---|---|---|
| Cd | 0.552（裸杆基准 0.397） | 同速总阻力 +14.6%，射程代价 ~0.4 m |
| 滚转力矩 M_roll | 0.00226 N·m（Cm=0.0158） | 滚 90° 需 0.4~0.5 s，飞行 1.6 s → 权限充足 |
| 铰链力矩 | ~0.0003 N·m | 舵机扭矩余量 >1000×，按重量/速度选舵机 |
| 载荷分布 | 舵面自身 70% + 渗透到共面定翼 30% | 连接段刚度设计按此分配 |
| 侧向副作用 | 0.065 N → 0.36 m/s² | 混控耦合项，可建模可修正 |
